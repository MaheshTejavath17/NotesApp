# Simple Notes App

## Mini Project
A simple Android multi-screen Notes App developed using Java in Android Studio.

## Features
- Three connected screens: Home, Add Note, and View/Edit Note
- Add new notes
- View and edit existing notes
- Delete notes
- Local data storage using SharedPreferences
- Notes remain available after closing and reopening the app

## Technologies Used
- Java
- Android Studio
- XML layouts
- SharedPreferences
- JSON for storing note data

## Navigation
Home Screen → Add Note Screen → Save → Home Screen
Home Screen → Select Note → View/Edit Screen → Update/Delete → Home Screen

## How to Run
1. Open Android Studio.
2. Select Open and choose the NotesApp folder.
3. Allow Gradle to sync.
4. Run the application on an emulator or Android device.
